# Student Performance Prediction System

## Project Description
The Student Performance Prediction System is a machine learning-based application that predicts a student's academic performance based on various factors such as study hours, attendance, previous marks, assignments, and other academic details. The system helps students and educators identify performance trends and take timely actions to improve learning outcomes.

## Features
- Predicts student academic performance
- User-friendly interface
- Accepts student input data
- Displays predicted results
- Helps identify students who may need academic support
- Easy to use and understand

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Tkinter (GUI) / Flask (Web Application)

## Installation

1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python app.py
```

## Dataset

The system uses a dataset containing student academic information such as:

- Study Hours
- Attendance
- Previous Exam Marks
- Assignment Scores
- Internal Assessment
- Participation
- Final Result

## Machine Learning Model

The prediction model is trained using machine learning algorithms such as:

- Linear Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

## How It Works

1. Enter student details.
2. Click the **Predict** button.
3. The system processes the input using the trained model.
4. The predicted student performance is displayed.
